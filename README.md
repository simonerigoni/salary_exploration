## Introduction

The idea is to automatically search on [payscale.com](https://www.payscale.com/) the salary for a list of jobs in different countries and visualize the results with a Dash web application.

## Software and libraries

This project uses Python 3.15 and the most important packages are:

- [Pandas](https://pandas.pydata.org): read and write the CSV files
- [Selenium](https://pypi.org/project/selenium/): drive Firefox to scrape the salaries
- [Dash](https://dash.plotly.com/) and [Plotly](https://plotly.com/python/): the web application

## Local configuration

To set up a local environment and install all dependencies, run `uv sync` from the project folder.

The notebooks need a few extra libraries. Install them with:

```bash
uv sync --group notebook
```

Then run the checks with:

```bash
uv run pre-commit run --all-files
uv run pytest
```

## Code quality

Code quality is maintained through automated checks and linting using pre-commit.

Pre-commit is a framework for managing and maintaining multi-language pre-commit hooks. A pre-commit hook is a script that runs before a commit operation in a version control system. This allows to shift left code quality checks and remediations. You can change the hooks by updating the file `.pre-commit-config.yaml`.

To trigger the pre-commit hooks without an actual commit you can run `uv run pre-commit run --all-files -v`.

It is also possible to run manually the individual tools:

- `uv run ruff check --fix`
- `uv run ruff format .`
- `uv run pyright .`

## Testing

Tests are implemented using `pytest` and coverage is tracked with `pytest-cov`. The detailed coverage report is generated by the pre-commit hook and it is available in [COVERAGE.md](COVERAGE.md) file.

It is also possible to run manually the individual tests:

- `uv run pytest`
- `uv run pytest tests/test_transform.py`

The tests never open a browser: the scraping steps that need Firefox are replaced with fakes.

## Running the code

<pre>
|-- salary_exploration: project folder
    |-- dash_app.py: web application to visualize the data
    |-- src/salary_exploration: the package
    |   |-- config.py: folders, filenames and default search
    |   |-- exploration.py: runs an exploration (the salary-exploration command)
    |   |-- extract.py: scrapes the salaries from payscale.com
    |   |-- transform.py: converts the salaries to Euro
    |   |-- browser.py: opens Firefox with Selenium
    |-- tests: one test module per module
    |-- notebooks: exploratory data analysis
    |-- search: optional countries.csv and jobs.csv to search
    |-- data: one folder per exploration, see data/DATA.md
</pre>

### Console

Every exploration is identified by a `YYYYMMDDTHHMMSSZ` date string, its UTC start time. To run a new one:

```bash
uv run salary-exploration
```

First you can place in the `search` folder the files:

- `countries.csv`: list of the countries to search (column `Country`)
- `jobs.csv`: list of the jobs to search (column `Job`)

If no file is provided, a default list is used for demo purposes. The command then creates `country_job_salary.csv` by scraping the [payscale.com](https://www.payscale.com/) website with Firefox, so Firefox must be installed.

Finally the data is transformed to convert the salary from local currency to Euro and saved in `country_job_salary_transformed.csv`. Salaries already in Euro are converted offline; other currencies are converted with a Google search.

Passing the date string of an existing exploration skips the scraping and only redoes the transformation:

```bash
uv run salary-exploration --date_string 20260310T115628Z
```
